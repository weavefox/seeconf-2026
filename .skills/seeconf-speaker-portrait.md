# SEE Conf 水彩半身人物

把一张真人照片处理成可直接用于嘉宾列表的独立头像素材。默认交付一个 **512×512、RGBA、透明 PNG**；图中包含完整的「人物上半身＋背后水彩异形色块」。透明的是两者之外的区域，不能把彩色背景块一起抠掉。

## 输入与参考的职责

- 用户提供的真人照片：唯一的人物身份依据，保留五官比例、脸型、年龄感、肤色、发型、眼镜等可辨识特征，以及原有朝向和神态。
- [风格参考](references/style-reference.png)：仅参考人物质感、半身裁切、水彩轮廓和前后遮挡。图中人物的脸、发型、衣领款式和视线方向不用于替换输入人物；下方姓名、职位和另一人的局部全部忽略。
- 用户在当前任务给出新的风格参考时，以新参考为准。没有真人照片时才请求提供照片，不从参考里的嘉宾生成一个替代人物。
- 默认每位人物一张、青蓝色背景。用户指定时可改为珊瑚红；不要未经要求自动生成两种颜色或其他版本。

## 视觉规则

### 人物

- 保留真人摄影的身份辨识度，呈现轻度编辑插画质感：细腻纸张颗粒、少量水彩干刷纹理、适度简化明暗。缩至 512 像素后仍能看清眼鼻口，不把噪点当肌理。
- 仅保留完整头部、颈部、双肩与胸口上段。不是腰部以上的长半身，不带手部、腿部或椅子。
- 穿无 Logo 的纯黑上衣。原图已经是黑衣时保留领型与结构；原图为其他颜色时优先沿用其款式改成黑色，保留必要的布料层次，避免纯黑剪影。
- 发丝与肩部抠边自然；衣服下缘为轻微不对称的圆弧收口，与背景组成完整头像轮廓，不出现横贯方形画布的生硬水平裁切线。
- 不改成漫画脸、动漫、3D 塑料皮肤、粗重油画、厚描边或过度磨皮；不擅自美化、年轻化、换脸、换发型、加饰品或镜像人物。

### 水彩背景的形状与层级

- 背景是单独位于人物后方的一整块水彩色块，而非原照片的环境背景，也不是铺满方形画布的背景。
- 参考轮廓接近**横向舒展、略倾斜的不规则圆角三角／圆润卵石**：左侧较低、向外鼓出，右侧较高且饱满，顶部为偏置的圆弧，底部宽缓；不是标准圆、椭圆、矩形或规整徽章。
- 中心有一定色彩饱和度，边缘有水彩晕染、透明度变化和纸纤维颗粒。轮廓应可辨认且完整，不做大范围散雾、飞溅碎点或外发光。
- 默认色彩为浅青、湖蓝到较深青蓝的自然变化；珊瑚红版本为浅桃粉、珊瑚红到暖红的同类变化。保持同一材质和轮廓语言。
- 色块在人物左右肩外侧及头部两侧可见；头顶和部分发丝伸出色块上缘，人物遮住中下部色块，形成前后层次。色块不覆盖面部，不画成人物后脑的光环。
- 色块直接画在透明底上，颜料下方没有黑色、灰色或任何不透明画布。颜料集中的区域不透明，颜料稀薄的留白处透出透明背景，色块边缘自然消溶于透明而非渐变到暗色。
- 整个人物和完整色块都放进画布，不截断头发、肩部、衣服下缘、左右水彩边缘或底部轮廓。只移除照片环境与参考网页底色。

### 画布与透明度

- 正方形构图，主体居中，视觉重心稳定；先将人物和背景作为一整个组合处理，再等比放进最终画布。
- 最终默认四周至少留 16 像素透明安全边距。此值是可调整的排版参数；用户有新的占比要求时随之调整，不能靠裁掉内容放大头像。
- 透明区域必须是真正的 Alpha。不得把白底、灰底或棋盘格画进图片；不能用全局去白把皮肤高光和浅水彩一并删掉。
- 水彩色块画在透明底上，不设黑底、深色或不透明画布。人物和彩色水彩是画面仅有的不透明内容；两者之外以及水彩颜料的稀薄留白处均为真 Alpha 透明。
- 不输出姓名、职位、文字、Logo、边框、卡片、网页组件或投影。

## 生成与导出

1. 查看真人照片和风格参考，明确身份与风格两类参考的职责。只创建 skill 或解释做法时，不自动提交生图任务。
2. 用户要求实际转换时，读取可用的 `huamei-aigc` skill 及其图片生成指南。默认通过用户已认证的 **Huamei CLI，使用 `gpt-image-2`**；不能静默切换其他供应商或 Codex 内置生图配额。画眉不可用时如实报告具体阻塞。
3. 将真人照片放在 `input_images` 第一张、风格参考放在第二张，并在提示词中明确对应职责。按当前画眉指南使用图片模板及 `--output agent-content`、`--raw`、`type=ImageList`，设置 `creativeNum=1` 和 `background="transparent"`。
4. 直接请求 512×512 的正方形生成稿，生成尺寸即最终交付尺寸，避免缩放导致的透明度损失。若服务端不支持该工作尺寸，以其实际支持的最接近的正方形尺寸为准，不反复盲试。
5. 若任务处理中且返回 `batchId`，只查询该任务，不重复提交。检查返回画面是否同时保留了真人辨识度、完整水彩色块和轻微肌理；发现具体缺陷时才针对它迭代。一次修正仍不合格时说明差异并等待用户决定，不无限消耗额度。
6. 实际执行本 skill 的交付目标包含本地 PNG。将结果保存到用户指定的目录；未指定时使用当前项目既有素材／输出位置。不创建额外项目目录，不覆盖真人原图。后续导出工具需要本地路径时，可为导出保存生成稿；保存位置沿用同一输出约定，不另建临时目录。
7. 用 [导出工具](scripts/export_portrait.py) 进行不改变内容的等比缩放和透明留边。脚本保留人物与水彩的联合 Alpha 轮廓，输出 512×512 RGBA PNG，并拒绝无透明度、全透明或已有边缘截断迹象的输入。它不负责去背景或重画人物。

```bash
python3 <skill目录>/scripts/export_portrait.py <已保存的生成稿> <最终文件.png>
```

脚本依赖 Pillow；优先使用环境中已有 Pillow 的 Python。默认文件名可采用 `<原照片名>-水彩半身像-512.png`。最终回复链接／展示这一个成品，不把生成稿当作已验收成品。

## 交付前检查

- **像本人**：与真人原图对照五官、脸型、发型、眼镜和朝向；没有混入参考人物的特征。
- **像参考**：真人半身＋黑衣＋轻纸感肌理，头部露出水彩块上缘；水彩完整可见，保持不规则圆润形状。
- **可用**：实际文件为 512×512 PNG，带有效透明通道，四周有透明留白，没有白矩形或伪透明棋盘格；浅色、深色背景上查看边缘均无明显白边或漏抠。
- **无多余元素**：没有文字、手、腰部、场景底色、额外人物或肩部硬切。
- 分别报告文件规格检查与视觉检查的真实结果；未做实际生图时，只说明 skill 已创建并验证，不能声称生成效果已通过验收。
